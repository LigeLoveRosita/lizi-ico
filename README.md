## English

### Features

- **Pure Frontend**: No backend required, all processing done in the browser
- **Multiple Format Support**: Convert images to ICO format (favicon)
- **Multi-language Support**: English, Traditional Chinese, Simplified Chinese
- **Easy to Use**: Drag and drop or click to upload
- **Real-time Preview**: Instantly preview the converted icon
- **Multiple Sizes**: Generate icons in various standard sizes (16x16, 32x32, 48x48, 64x64, 128x128, 256x256)
- **No Upload**: Your images never leave your device

### Supported Input Formats

- PNG
- JPEG / JPG
- GIF
- BMP
- WebP
- SVG

### How to Use

1. Open `index.html` in any modern web browser
2. Drag and drop an image onto the page, or click to select a file
3. Select the icon sizes you want to generate
4. Click the "Convert" button
5. Download the generated ICO file

### Browser Compatibility

- Chrome 80+
- Firefox 75+
- Safari 13+
- Edge 80+

### File Structure

```
/
├── index.html          # Main application file
├── favicon.ico         # Sample ICO file
├── main.jpg            # Sample image for testing
└── README.md           # This file
```

### Technical Details

- HTML5 Canvas API for image processing
- Blob API for file handling
- Internationalization (i18n) for multi-language support
- Responsive design for all screen sizes
